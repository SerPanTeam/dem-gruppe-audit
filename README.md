# DEM Gruppe — External Digital Audit

Externer Web-, SEO- und Digital-Audit für **dem-gruppe.de**.

**Start:** 09.11.2026  
**Autor:** Serhii Panchenko  
**Scope:** ausschließlich öffentlich zugängliche Daten, externe SEO-Datenbanken, Crawl und öffentlich sichtbare Website-Inhalte. Keine internen Zugänge.

## Struktur

- `index.html` — Kundenbericht (in Arbeit)
- `docs/` — interne Notizen (nicht auf GitHub Pages, siehe `_config.yml`)
- `data/` — aufbereitete Daten (CSV/JSON)
- `assets/evidence/` — Screenshots als Belege
- `raw/` — Rohexporte, lokal, nicht im Repo

## Veröffentlichung

GitHub Pages „Deploy from a branch“ (`main`, Root). GitHub Actions sind auf dem Konto wegen Billing blockiert.

## Hinweis

Werte aus SEO-Datenbanken sind externe Schätzwerte und ersetzen keine Google-Search-Console-/GA4-Daten.
